# ICOproyectoSmestre1
Este sera el proyecto del graficos/nodos/aristas/clases/etc.

Para la creacion de este proyecto utilizamos Flask, esto debido a que viene integrado dentro de Pycharm y nos facilito mucho el proceso
del setup para la conexion.

Este proyecto consiste de un mapa de dos dimensiones de Cetys Universidad, el proposito principal de este proyecto es crear un mapa 
donde puedas seleccionar alguna ubicacion dentro de cetys y el mapa puede decir la ruta mas corta hacia algun edificio o 
algun baño, cafeteria o punto de reunion.
